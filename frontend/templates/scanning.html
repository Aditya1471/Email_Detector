Understand Security Terms
SPF Policy (Sender Policy Framework) Validates whether the sending server has authorized permission from the domain owner. If unaligned, anyone can spoof that email name!
DMARC Alignment A DNS rule that tells servers how to handle failures. Tight alignment blocks or flags spoofed messages automatically.
Typosquatting Check Checks spelling similarity (e.g. paypa1 instead of paypal) using Levenshtein distance calculations to flag brand impersonations.
WHOIS Domain Age Fraud domains are usually registered very recently. Brand new domains (under 30 days) automatically trigger alert weights.
