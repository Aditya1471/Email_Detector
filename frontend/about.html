Architecture & Principles

Explainable Email Threat Intelligence

PhishGuard combines machine learning, heuristic indicator extraction, and delegated inbox monitoring to help users understand suspicious emails before taking action.

1. Explainable ML Engine

Instead of returning an opaque "black-box" score, PhishGuard exposes the individual heuristic rules, keyword weights, and sentiment signals that informed the classification.

2. Continuous Ingestion

Using Google Gmail API and Microsoft Graph webhooks, PhishGuard periodically polls recent messages asynchronously using Celery background workers.

3. Privacy by Design

Full email bodies and attachments are never stored in the database. OAuth tokens are encrypted at rest with Fernet cryptography.

Privacy Safeguards & Data Minimization

In-Memory Inference Architecture

When you submit an email for analysis, the text is processed strictly in-memory during inference. The server extracts security metadata (sender domain, threat flag count, risk score) and discards the raw body payload immediately.

User Data Ownership & Purging

You maintain total control over your connected accounts. You can pause monitoring, disconnect integrations, and purge all historic metadata logs with a single click at any time.

Technical Security Controls

Fernet AES-128 Token Encryption

OAuth access and refresh tokens from Google and Microsoft are encrypted at rest using Fernet symmetric encryption before being written to PostgreSQL.

Defensive Isolation

PhishGuard never executes attachments or crawls suspicious URLs. Domain evaluation is performed using offline parsing and heuristic lookups to ensure total host safety.

System Disclaimer & Advisory Notice

PhishGuard provides automated risk indicators and heuristic threat flags to assist user judgment. PhishGuard does not guarantee that an email is 100% safe. Always verify unusual financial requests or credential prompts through an out-of-band communication channel.
